Mais do que desenhar interfaces, busco resolver problemas reais por meio de produtos digitais que façam sentido para quem usa e gerem valor para o negócio.

How I work

Como eu trabalho

  • Evidence-based design

    Design baseado em evidência

    Decisions come from stakeholder interviews, real data and system constraints, not from intuition alone.

    As decisões vêm de entrevistas com stakeholders, dados reais e restrições do sistema, não só intuitivamente.

  • Visual hierarchy

    Hierarquia visual

    Not every element should compete for the same attention. Visual hierarchy guides the user's eye and communicates priorities through size, weight, color, contrast, and spacing.

    Nem todos os elementos devem competir pela mesma atenção. A hierarquia visual guia o olhar e comunica prioridades por meio de tamanho, peso, cor, contraste e espaçamento.

  • Minimalism with intent

    Minimalismo com intenção

    Remove until only what the user needs to decide is left, then make that part obvious.

    Remover até sobrar só o que o usuário precisa para decidir, e então tornar isso óbvio.

  • Systems over screens

    Sistemas, não telas

    I build experiences with reusable patterns and components, creating consistency and making every new screen faster and easier to design.

    Construo experiências a partir de padrões e componentes reutilizáveis, criando consistência e tornando cada nova tela mais rápida e simples de projetar.

  • Responsive by default

    Responsivo por padrão

    App, desktop and responsive web designed together: the same logic adapting, not three separate products.

    App, desktop e web responsiva desenhados juntos: a mesma lógica se adaptando, não três produtos separados.

  • Every state designed

    Todos os estados desenhados

    Empty, loading, error, expired, used. The happy path is the easy half of the job.

    Vazio, carregando, erro, expirado, utilizado. O caminho feliz é a metade fácil do trabalho.
